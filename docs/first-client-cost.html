The short version. One rented server runs the entire product: the CRM, the company websites, the API and the database. Domains, security certificates, firewalls and backups are either included or free. For our first client we would also cover their domain and their email, so they receive one working system at no cost to them.

2  What is already free

  • Security certificate (SSL) for every domain — automatic and renewed for us
  • Firewall, attack protection and global content delivery
  • DNS and bot protection on sign-up
  • Database, web server and application software — all open source
  • Uptime monitoring and alerts
  • Unlimited traffic within normal use

$0 per year. These are not trials — they are permanent free tiers we can start on and grow out of later.
